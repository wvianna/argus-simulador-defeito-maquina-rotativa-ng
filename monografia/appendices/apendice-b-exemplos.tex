\section{Picos observados para rolamento BPFI}

Transcrição parcial da resposta real (1800\,rpm, \(f_s=25600\)\,Hz, \(N=8192\)):

\begin{verbatim}
f= 131.25 Hz (ordem  4.38N)  A=0.1205   <- BPFI - 1X
f= 162.50 Hz (ordem  5.42N)  A=0.6664   <- BPFI
f= 190.62 Hz (ordem  6.35N)  A=0.0973   <- BPFI + 1X
f= 293.75 Hz (ordem  9.79N)  A=0.0627   <- 2xBPFI - 1X
f= 325.00 Hz (ordem 10.83N)  A=0.2359   <- 2xBPFI
f= 353.12 Hz (ordem 11.77N)  A=0.0553   <- 2xBPFI + 1X
f= 487.50 Hz (ordem 16.25N)  A=0.0933   <- 3xBPFI
\end{verbatim}


A resolução espectral da configuração é \(\Delta f = 25600/8192 =
3{,}125\)\,Hz, o que explica os pequenos desvios em relação às frequências
teóricas.
